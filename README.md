# 蓝色动力学 · 物理海洋学入门

一个中文物理海洋学知识介绍网站，灵感来自海洋主题的视觉叙事与信息图解。项目使用原生 HTML、CSS、JavaScript 构建，无需构建工具即可运行和部署到 GitHub Pages。

制作成员：孙智豪

English edition: open `en.html`. Both language versions share the same visuals, assets, and interactive components.

## 内容

- 评分证据索引：15 项要求逐条映射到八次课堂档案、三处教材证据、课堂—教材对照、延伸数据源与完整故事制作链路
- 进阶动力学：位势涡度、Sverdrup 平衡与 β 效应，以及风驱大洋环流的概念链
- 研究工具箱：学习检索、海洋观测和数据可视化的权威资源入口与推荐工作流

- 海水的温度、盐度、压力与密度
- 风驱动表层环流、温盐环流与全球输送带
- 波浪、潮汐、上升流和海气相互作用
- CTD、卫星遥感、Argo 浮标等观测手段
- 海水密度交互实验：拖动温度和盐度滑块，观察密度与运动趋势
- “出门票”学习出口：用五个可勾选任务复盘 AI 学习、位势温度、RAWGraphs、EOF/地转平衡与后续问题，并提供可展开的参考答案
- 学习文档配图：物理海洋学知识框架、海洋时空尺度、Argo 温盐图与地转平衡示意图
- EOF 分析面板：以热带太平洋海温异常为例，交互展示 EOF 1/EOF 2 的空间模态、主成分时间系数与方差贡献
- 九个核心问题：以可展开的学习卡片串联混合层、温跃层、温盐结构、淡水收支、盐度、季节性、密度、地转流与 ENSO
- 参考书目：以《物理海洋学》*Descriptive Physical Oceanography: An Introduction* 为基础阅读材料，串联九问、出门票和 EOF 分析
- 故事会：南大洋冰间湖的叙事板块，含冰间湖成因、极夜观测影像与本地卫星风格图片资源

## 本地运行

冰间湖科普视频模块：`#polynya-film`，包含本地两分钟 MP4、封面、内嵌中文字幕、可选 WebVTT 字幕轨及 SRT 下载。英文页面提供英文介绍，视频旁白仍为中文。

直接用浏览器打开 `index.html` 即可。也可以使用任意静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## GitHub Pages 部署

将仓库推送到 GitHub，在 **Settings → Pages** 中选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存后即可获得公开网址。

站内数值和示意图用于教学表达，不替代专业海洋观测数据。页面内容以物理海洋学基础概念为主，适合入门阅读。
